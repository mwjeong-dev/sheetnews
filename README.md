# Sheet News

연합뉴스 RSS를 엑셀 스타일 표로 표시하는 정적 HTML 뉴스 뷰어입니다.

`index.html`과 `news.xml`을 함께 정적 웹 서버로 제공하면 됩니다. 예:

```bash
npx serve .
```

`news.xml`은 연합뉴스 RSS의 내려받은 사본입니다. 정적 HTML은 브라우저 보안 정책상 실행 시 파일을 자동 저장할 수 없으므로, 최신 기사 반영은 이 파일을 다시 내려받아 교체해야 합니다.

다음 명령으로 사본을 갱신할 수 있습니다. 외부 패키지는 필요하지 않습니다.

```bash
python3 update_news.py
```

현재 연합뉴스 RSS 응답에는 브라우저 직접 요청을 허용하는 CORS 헤더가 없으므로, 서버 PC에 배포할 때는 `/api/news` 같은 동일 출처 RSS 프록시를 추가하고 `RSS_URL`을 그 경로로 바꾸면 자동 갱신이 가능합니다.
